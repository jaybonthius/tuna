* Robustness
** DONE event loop has no error handling around command dispatch

Resolved: ~event-loop.rkt~ wraps command dispatch in ~with-handlers ([exn:fail?
handle-loop-error!])~; ~handle-loop-error!~ reports the error to the echo line
and keeps the loop alive, deliberately letting ~exn:break~ / custodian shutdown
through. (Originally surfaced when a malformed ~~user~ made ~expand-file-name~
raise on the loop thread.)

* Dired / directories in find-file
** TODO selecting a directory in find-file

Right now ~C-x C-f~ on a directory refuses it with a message ("X is a
directory") and does not open it. It also cannot overwrite a directory — the OS
rejects renaming a file over a dir, so there is no data-loss path. Emacs opens
dired on a directory. When we have a directory editor (or a "navigate into"
affordance), make selecting a directory open/enter it instead of erroring.
