# Tuna

Tuna is an extensible, browser-rendered computing environment in the spirit of Emacs, written in [Gerbil Scheme](https://cons.io).

## Install

With Gerbil on `PATH`:

```sh
./install.sh
```

## Build and run from source

Requires Gerbil v0.19 and esbuild on `PATH`.

```sh
make deps
make
make run
```
