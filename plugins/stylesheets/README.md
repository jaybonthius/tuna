# stylesheets

Which CSS files are on the page, in what order, and who replaced which. The contract gives `add-stylesheet` and `replace-stylesheet` to plugins, themes and `init.ss`; Gerbil code never holds colours or styles.

The package's plugin, `design-tokens`, adds the raw design scale (palettes, sizes, fonts) as one stylesheet, `(design-tokens tokens)`, which other plugins' semantic tokens use. Option: `variant:` (`stellar-default`). `make tokens STELLAR=…` regenerates the file; `agents/guides/design-tokens.md` lists the tokens plugins may use.

`M-x describe-stylesheets` and `M-x reload-stylesheets` are in the help plugin.
