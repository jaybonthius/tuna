# stylesheets

Which CSS files are on the page, in what order, and who replaced which. The contract gives `add-stylesheet` and `replace-stylesheet` to plugins, themes and `init.ss`; Gerbil code never holds colours or styles.

The package's plugin, `stylesheets`, adds the raw design scale (palettes, sizes, fonts) as one stylesheet, `(stylesheets tokens)`, which other plugins' semantic tokens use. Option: `variant:` (`stellar-default`). `make tokens STELLAR=…` regenerates the file; `agents/guides/design-tokens.md` lists the tokens plugins may use.

A second stylesheet, `(stylesheets fonts)` (`tokens/fonts.css`), ships Tuna's monospace font, Fira Code Nerd Font (`tokens/fonts/`, WOFF2 converted from the Nerd Fonts release with fontTools), and puts it first in `--font-mono` and `--font-monospace-code`, which the page, the terminal and code use. Replace that stylesheet to use another font.

`M-x describe-stylesheets` and `M-x reload-stylesheets` are in the help plugin.
