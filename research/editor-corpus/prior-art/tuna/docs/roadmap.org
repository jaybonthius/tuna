#+title: Tuna roadmap

* Direction

Tuna is a local, personal Emacs-like editor written in Racket. The Lisp core is
the priority: terminals, Git, syntax highlighting, LSP, and projects must use
the same public APIs available to user configuration.

Actionable feature headings carry stable Org IDs. See
[[file:agents/backlog.md][the feature backlog convention]].
