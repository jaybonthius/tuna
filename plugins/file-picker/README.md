# file-picker

Reads file names with completion, listing each folder in a job, for `C-x C-f`, `C-x C-w` and any other question for a file name, and binds `C-x C-f` to visit a file and show it. It also picks among the files visited last, with `M-x file-picker:find-recent-file` or as a source of `C-x b`.
